# Structural Entropy Survey

Focus: a decade survey of structural entropy since the 2016 TIT paper, covering
theory, optimization, graph clustering, graph neural networks, dynamics,
reinforcement learning, and reproducibility.

Recommended framing: survey plus taxonomy plus benchmark plus companion library.
The library should support the survey as an artifact, not replace the paper's
intellectual contribution.

## IJCAI Survey Placement

Place the existing IJCAI survey materials under:

```text
docs/ijcai_survey/
```

Use the journal extension directory for the expanded version:

```text
docs/journal_extension/
```
