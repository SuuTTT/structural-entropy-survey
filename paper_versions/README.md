# Paper Versions

This directory keeps explicit manuscript versions for side-by-side comparison.

- `v0.0/`: snapshot of the original working TGINA manuscript before the writing-model rewrite.
- `v1.0/`: alternate manuscript version rewritten from the front using the Fortunato-style reverse-engineered writing model.
- `v1.1/`: traceable rewrite with explicit origin-model-rewrite mapping for the front sections.

Versioning rule for now:

- `V0.0` means the baseline working draft.
- `V1.0` means a deliberate prose-and-structure rewrite while preserving the same core survey content and bibliography.
- `V1.1` means the same rewrite direction, but with a documented sentence-function mapping from `V0.0` through the writing model into the new prose.

The goal is comparison, not replacement. We can keep advancing both until one clearly becomes the stronger journal draft.
